Testes autorais piloto, pacotes por módulo, convites individuais e dashboards integrados ao WooCommerce.

== Description ==
Quatro módulos de desenvolvimento com aplicação individual, salvamento de respostas e relatórios por dimensão. Os instrumentos são autorais piloto, sem equivalência oficial aos produtos DISC e PEAKS de referência.

== Installation ==
Ative o WooCommerce, envie o ZIP do plugin e acesse Nortume no painel. Crie os produtos iniciais em rascunho, revise os questionários e defina os preços.
